# 웰촌과 체험마을 AI사무장

확인일: 2026-10-16

## 1. 결론

웰촌은 농림축산식품부·한국농어촌공사의 **전국 관광객용 농촌여행 포털**이다. 체험마을 AI사무장은 그 포털을 대체하지 않고, **광주·전남 마을 운영자**가 카카오톡으로 예약·홍보를 처리하게 하는 보완 도구다. 이 입장은 [My_Ai_Lab_SRD.md](My_Ai_Lab_SRD.md)의 기존 범위 정의와 같다.

## 2. 확인 범위

개편 배경은 [한국농어민신문 2025-01-07](https://www.agrinet.co.kr/news/articleView.html?idxno=333575)를 따랐다. 기사 수치(자원 건수)는 2025년 1월 기준이다.

농촌체험휴양마을 사업관리시스템(RUCOS)은 웰촌과 함께 유지관리된 별도 시스템으로 보도에 나온다. 이번 비교 URL의 기능으로는 적지 않는다.

## 3. 웰촌에서 확인한 기능

푸터의 주소·사업자등록번호·대표전화(1577-1417)는 한국농어촌공사 농촌 담당 연락처다. 소개 문구는 “웰촌은 농촌여행정보포털”이다. 메인 슬로건은 “농촌여행의 모든 것”이다.

공개 화면에서 다음을 확인했다.

- 여행지 검색: 시도, 시군구, 체험 분류, 비용, 인원, 계절. 지도에서 시도·시군구를 고른다.
- 편집 코너: 이달의 웰촌, 계절·테마 코스, 여행 이야기, 스타마을.
- AI 챗봇 **촌식이**: 여행지, 계절·테마, 촌캉스 상품, 여행 스토리, 기차역 시설을 대화로 안내한다. 2024년 말 개편에서 ChatGPT 기반 챗봇으로 들어왔다.
- 촌캉스 상품관: 가격이 있는 패키지. 상품 문의는 웰촌투어 1577-1233.
- 농촌관광등급: 체험·음식·숙박을 1~3등급으로 나누고, 세 부문 모두 1등급이면 으뜸촌이다.
- VR농촌여행, 나만의 여행(지도에서 일정을 넣는 화면).
- 2025년 1월 기사: 농촌관광 자원에 한국관광공사 정보를 이어 축제·관광지·음식·카페·숙박까지 넓혔고, 정보 규모는 약 5만 건이다.

여행 이야기 본문에는 마을 예약이 전화 상담으로 안내된 예가 있다. 결제 화면과 마을 운영자용 예약 관리 화면은 이 공개 URL에서 확인하지 않았다.

## 4. 체험마을 AI사무장의 현재 구현

지역은 광주·전남(광주 5개구, 전남 22개 시·군)이다.

관광객용으로 자연어 마을 추천, 지도, TourAPI 주변정보, 공개된 마을 홍보 화면이 있다. 글이 없으면 체험명과 시군구를 보여 준다.

운영자용으로 카카오톡 채널 하나에서 예약 접수, 예약 현황, 승인, 거절, 후기를 처리한다. 웹에서는 로그인한 운영자의 마을만 본다. 사진 한 장 또는 짧은 설명으로 담당 마을 소개글·SNS 초안을 만들고, 운영자가 공개한 뒤에 마을 화면에 나온다. 공공데이터 프로그램 글은 항목으로 나누고, 담당 운영자가 중지를 누르면 그 항목만 마을 소개와 카카오 추천에 `지금은 운영하지 않음`으로 나온다. 기본은 운영 중이라 그 문구를 붙이지 않는다.

신뢰도 점수는 후기를 반영한다. 정부 등급을 대신하지 않는다.

결제, VR, 전국 편집 콘텐츠, 비즈월렛·이벤트 API 선톡은 이번 단계에 없다.

## 5. 겹쳐서 차별점이 아닌 것

| 기능 | 웰촌 | 체험마을 AI사무장 |
|---|---|---|
| 마을 목록·지역 필터 | 전국 시도·시군구, 분류·비용·인원·계절 | 광주·전남 시군구·체험 유형 |
| 자연어 추천 | 촌식이가 여행지·상품·스토리·계절·기차역을 안내 | 질문으로 광주·전남 마을을 고르고 한 줄 이유를 붙임 |
| 주변 관광정보 | 포털 안에서 관광공사 연계 정보까지 확장(2025년 1월 기사) | 마을 위치 기준 TourAPI 카드 |
| 계절 추천 | 이달의 웰촌, 계절·테마 코스(편집) | 질문 조건에 맞춰 후보를 고름 |

## 6. 남는 차별점

| 구분 | 웰촌 | 체험마을 AI사무장 |
|---|---|---|
| 주 사용자 | 전국 관광객 | 광주·전남 마을 운영자. 관광객 추천은 같은 서비스 안의 다른 역할 |
| 예약 | 공개 화면의 상품은 전화 문의. 마을 예약 원장은 이 URL에서 확인하지 않음 | 카카오톡에서 접수·현황·승인·거절. 관광객은 본인 예약만 조회 |
| 홍보 글 | 포털 편집과 공식 정보 | 담당 마을 1곳만 초안을 만들고, 운영자가 공개 |
| 다루는 마을 | 이달의 웰촌·테마처럼 편집으로 고른 전국 여행지 | 광주·전남 공공데이터에 있는 마을. 글이 없어도 체험명·시군구는 표시 |
| 신뢰 표시 | 체험·음식·숙박 등급과 으뜸촌 | 후기 기반 신뢰도 점수 |
| 지금 하는 체험 | 2026년 9월 이달의 웰촌은 `웰촌 PICK 추천 여행지`다. 문구는 `웰촌만의 노하우로 고객님께 여행지를 추천합니다.`이고, 화면에 보인 표제는 `온 가족이 만족하는 추석 농촌여행`이다. 옆 탭은 `이달의 추천 으뜸촌`, `지금 뜨는 촌캉스`다. 운영자가 개별 체험의 중지를 바로 고치는 화면은 이 주소에서 확인하지 않았다 | 공공데이터 글을 항목으로 나누고, 담당 운영자가 지금 하지 않는 항목만 중지한다. 마을 소개와 카카오 추천은 그 항목만 `지금은 운영하지 않음`이라고 말한다. 가격·시간·새 프로그램·월별 편집 목록은 없다 |

운영자 웹은 자기 마을 예약·후기만 보여 준다. 다른 마을 번호로 요청하면 거부한다.

## 7. 웰촌에만 있는 것

- 체험·음식·숙박 공식 등급과 으뜸촌
- 가격이 붙은 촌캉스 상품과 웰촌투어 상담
- VR농촌여행
- 이달의 웰촌, 여행 이야기 같은 전국 취재 콘텐츠
- 웰촌·촌식이 브랜드와 공식 SNS

## 8. 제안서 4-2를 고친 이유

[My_Ai_Lab_Proposal.md](My_Ai_Lab_Proposal.md) 4-2는 웰촌을 “필터만 되고, 마을 정보만 있으며, 페이지가 방치됐다”로 적었다. 2024년 말 개편 이후 공개 화면에는 촌식이, 상품, 등급, VR, 관광공사 연계 정보가 있다. 웰촌은 데이터 보유 기관의 포털이므로, 이쪽 공공데이터 동기화가 웰촌보다 더 최신이라는 표현은 빼었다. 운영자용 카카오 예약·승인과, 사진·짧은 글로 담당 마을 글을 만드는 기능은 그대로 차별점이다.
