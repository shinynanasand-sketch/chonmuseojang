# 오픈빌더 시나리오 ↔ 스킬 연결 (필수)

스킬 URL만 등록하고 **적용 블록수 = 0**이면 카카오톡에서 말해도 웹훅이 호출되지 않습니다.  
아래대로 **시나리오 블록에 스킬을 연결**하세요. (탈출 블록 사용 금지)

## 전제

- 개발채널 연결됨
- 스킬 3개 존재: `예약`, `승인/거절`, `후기`
- URL:
  - 예약 → `https://chonmuseojang.vercel.app/kakao/booking`
  - 승인/거절 → `https://chonmuseojang.vercel.app/kakao/approve`
  - 후기 → `https://chonmuseojang.vercel.app/kakao/review`

## 단계

1. 오픈빌더 → **시나리오** → **시나리오 01** (또는 + 시나리오)
2. **+ 블록** 3개 생성:

### 블록 A — 예약

| 항목 | 값 |
|---|---|
| 사용자 발화 | `예약`, `예약할게요`, `체험 예약` |
| 스킬 검색/선택 | **예약** |
| 파라미터 | `visit_date`, `num_people` (스킬 정의에 맞게 연결) |

### 블록 B — 승인/거절

| 항목 | 값 |
|---|---|
| 사용자 발화 | `승인`, `거절`, `예약 승인` |
| 스킬 검색/선택 | **승인/거절** |
| 파라미터 | `booking_id`, `decision` (`approve` / `reject`) |

### 블록 C — 후기

| 항목 | 값 |
|---|---|
| 사용자 발화 | `후기`, `리뷰`, `후기 남길게요` |
| 스킬 검색/선택 | **후기** |
| 파라미터 | `booking_id`, `rating` (본문은 발화) |

3. 각 블록 **저장**
4. **스킬 목록**으로 돌아가 **적용 블록수**가 1 이상인지 확인
5. 상단 **봇테스트**에서 `예약` 입력 → 스킬 호출되면 OK

## 스킬서버 PASS 후 — 봇테스트 (지금 할 일)

스킬 **「스킬서버로 전송」**이 `올바른 스킬 서버 응답입니다`이면 서버는 준비된 상태입니다.  
봇테스트가 비어 보이면 **시나리오 블록**만 손보면 됩니다.

1. 왼쪽 **시나리오** → **예약** 블록 열기  
2. **스킬 검색/선택** = `예약` 확인  
3. 아래에 **글자 없는 텍스트/카드 말풍선**이 있으면 **삭제** (스킬 응답만 사용)  
4. **Ctrl+S** 저장  
5. 오른쪽 **봇테스트**에 입력 후 **테스트**:  
   - `예약`  
   - 또는 `2026-09-30 2명 예약`  
6. 「예약이 접수되었습니다…」 말풍선이 보이면 OK  

스킬 URL이 ping으로 남아 있으면 예약 URL로 되돌리세요:  
`https://chonmuseojang.vercel.app/kakao/booking`

## 말풍선 포맷 오류 시 점검

「말풍선 포맷이 올바르지 않습니다」가 나오면:

1. **먼저 격리 테스트** — 스킬 URL / Test URL을 잠시 아래로 바꾼 뒤 「스킬서버로 전송」  
   `https://chonmuseojang.vercel.app/kakao/ping`  
   → 「스킬 연결 OK」가 나오면 서버 연결은 정상
2. 다시 예약 URL로 복구:  
   `https://chonmuseojang.vercel.app/kakao/booking`
3. **시나리오 → 예약 블록**: 스킬=`예약`만 두고, **내용 없는 텍스트/카드 말풍선은 삭제** 후 저장
4. 봇테스트 후 왼쪽 **작업이력**에서 응답 body에 `simpleText`가 있는지 확인  
   (요청 JSON이 아니라 **응답 JSON**)

## user.id 확인 (매핑용)

1. 봇테스트 또는 개발채널 채팅에서 메시지 1회
2. 왼쪽 **작업이력** (또는 스킬 디버그/요청 로그)
3. JSON에서 복사:

```json
"userRequest": { "user": { "id": "여기_복사" } }
```

4. [`../supabase/operators_kakao_map.sql`](../supabase/operators_kakao_map.sql)의 `'실제_카카오_사용자_ID'`를 그 값으로 바꿔 Supabase SQL Editor에서 Run

## 시연 순서

1. `예약` → 방문일·인원 → 예약번호 카드
2. `승인` + 예약번호 → 승인 완료 카드 (운영자 ID 매핑 후)
3. `후기` + 별점 → 후기 등록 완료 카드
