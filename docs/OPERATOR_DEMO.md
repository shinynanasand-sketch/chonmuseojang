# 시연 계정과 테스트 방법

웹에서 운영자 화면을 확인하는 값입니다. 스킬 서버, 오픈빌더 봇테스트, 실기기 시연은 끝났습니다. 비밀번호는 없습니다. 카카오 사용자 ID를 어디에 쓰고 어디에 쓰지 않는지는 [`PRIVACY_KAKAO_ID.md`](PRIVACY_KAKAO_ID.md)를 봅니다. 실기기 채팅 계정의 ID 값은 이 문서에 적지 않습니다.

## 웹에서 확인

1. https://chonmuseojang.vercel.app/operator 를 엽니다.
2. 로그인 아이디에 `owner_v001`을 넣고 **조회**를 누릅니다.

보여야 하는 내용입니다. 2026-10-06 실기기 시연 이후 기준입니다.

- 순위: 전체 187곳 중 1위, 신뢰도 60점
- 예약 7건, 대기 4건
- 예약 1번: 승인, 2026-12-01, 2명
- 예약 2번: 승인, 2026-12-15, 3명
- 예약 3번: 대기, 2026-09-30, 2명
- 예약 4번: 대기, 2026-10-13, 2명
- 예약 5번: 대기, 2026-09-30, 2명
- 예약 6번: 대기, 2026-11-20, 2명 (오픈빌더 봇테스트)
- 예약 7번: 승인, 2026-12-20, 2명 (실기기)
- 후기: 예약 2번 별점 4 `시연 후기입니다`, 예약 1번 별점 5, 예약 2번 별점 5 `후기`, 예약 7번 별점 5 `후기`

예시 마을 V001은 관광객 마을 목록·지도·추천에 나오지 않습니다. 순위는 로그인한 운영자 화면에서만 이 마을을 포함해 계산합니다.

## 카카오 사용자 ID

| 역할 | 값 | 쓰는 곳 |
|---|---|---|
| V001 운영자 | 실기기 채팅 계정의 `kakao_user_id` (값은 문서에 없음) | 카카오 승인·거절. 웹 로그인 칸에는 넣지 않습니다 |
| 시연 손님 | `kakao_guest_demo` | 2026-10-05 스킬 서버 예약·후기 식별자. 화면과 카카오 로그인에는 쓰지 않습니다 |
| 2026-10-05 스킬 서버 | `206405` | 예약 1번 승인 요청에 넣은 값. 지금 DB의 V001 운영자는 이 값이 아닙니다 |

웹 로그인 `owner_v001`과 실기기 채팅 계정은 같은 마을(V001, 예시 갯벌마을) 운영자입니다.

## 이미 한 승인

스킬 서버에서 예약 **1번**을 `206405`, `decision=approve`로 승인했습니다. 운영자 화면의 1번은 승인입니다.

오픈빌더 봇테스트의 승인·거절은 「등록된 운영자만 승인/거절할 수 있습니다」였고, 예약 3번은 대기로 남았습니다. 실기기에서 예약 **7번**을 승인했습니다. 후기 5번은 그 예약의 별점 5입니다.

승인 블록은 `booking_id` = `7`, `decision` = `approve`로 저장되어 있습니다. 후기 블록은 `booking_id` = `7`, `rating` = `5`입니다. 예약번호와 `decision`은 채팅 입력칸에 쓰지 않습니다. 그 문장을 넣으면 폴백 블록이 「무엇을 원하는지 잘 모르겠어요」라고 답하고 스킬은 호출되지 않습니다. 같은 발화를 다시 보내면 예약이나 후기가 더 생깁니다.

스킬 URL과 재개 순서는 [`KAKAO_RESUME.md`](KAKAO_RESUME.md)를 봅니다.

## 시드를 다시 넣을 때

```powershell
cd chonmuseojang
uv run python scripts/load_demo_fixtures.py
```

이미 있는 시연 예약·후기는 다시 만들지 않습니다. 승인된 1·2·7번을 대기로 되돌리거나 3·4·5·6번과 후기를 지우지 않습니다. `operators_kakao_map.sql`은 `206405`로 되돌리므로 다시 실행하지 않습니다.

`scripts/load_demo_seed.py`는 카카오 ID를 시드 값으로 덮으므로 실행하지 않습니다.
