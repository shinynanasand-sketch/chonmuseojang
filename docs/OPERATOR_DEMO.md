# 시연 계정과 테스트 방법

웹에서 운영자 화면을 확인하고, 나중에 카카오 승인 테스트를 같은 예약으로 잇는 값입니다. 비밀번호는 없습니다. 카카오 사용자 ID를 어디에 쓰고 어디에 쓰지 않는지는 [`PRIVACY_KAKAO_ID.md`](PRIVACY_KAKAO_ID.md)를 봅니다.

## 웹에서 확인

1. https://chonmuseojang.vercel.app/operator 를 엽니다.
2. 로그인 아이디에 `owner_v001`을 넣고 **조회**를 누릅니다.

보여야 하는 내용입니다.

- 순위: 전체 187곳 중 1위, 신뢰도 60점
- 예약 1번: 대기, 2026-12-01, 2명, 시연 손님
- 예약 2번: 승인, 2026-12-15, 3명, 시연 손님
- 후기: 2번 예약, 별점 4, `시연 후기입니다`

예시 마을 V001은 관광객 마을 목록·지도·추천에 나오지 않습니다. 순위는 로그인한 운영자 화면에서만 이 마을을 포함해 계산합니다.

## 카카오 사용자 ID

| 역할 | 값 | 쓰는 곳 |
|---|---|---|
| V001 운영자 | `kakao_user_id` `206405` | 카카오 승인·거절. 웹 로그인 칸에는 넣지 않습니다 |
| 시연 손님 | `kakao_guest_demo` | 위 예약·후기를 넣은 식별자. 화면과 카카오 로그인에는 쓰지 않습니다 |

웹 로그인 `owner_v001`과 카카오 ID `206405`는 같은 마을(V001, 예시 갯벌마을) 운영자입니다.

## 나중에 승인 테스트

카카오 수동 시연을 다시 시작할 때, 대기 중인 예약 **1번**으로 승인합니다.

1. 오픈빌더 승인 블록에서 예약번호 `1`, `decision=approve`를 보냅니다.
2. 그 발화의 카카오 사용자 ID가 `206405`일 때만 승인됩니다. 다른 ID면 「등록된 운영자만 승인/거절할 수 있습니다」가 나옵니다.
3. 승인 뒤 운영자 화면의 1번 예약은 승인으로 바뀝니다.

스킬 URL과 재개 순서는 [`KAKAO_RESUME.md`](KAKAO_RESUME.md)를 봅니다.

## 시드를 다시 넣을 때

```powershell
cd chonmuseojang
uv run python scripts/load_demo_fixtures.py
```

이미 있는 시연 예약·후기는 다시 만들지 않고, `kakao_user_id` `206405`도 바꾸지 않습니다.

`scripts/load_demo_seed.py`는 카카오 ID를 시드 값으로 덮으므로 실행하지 않습니다.
