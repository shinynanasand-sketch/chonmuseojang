# 개발자 메뉴얼

실제 마을 운영자를 카카오에 등록하고, 그 마을 홍보와 웹 로그인을 여는 절차입니다. 운영자가 보는 문장은 [카카오_등록_메뉴얼.md](카카오_등록_메뉴얼.md)와 [카카오_사용_메뉴얼.md](카카오_사용_메뉴얼.md)에 있습니다.

## 등록

실제 마을 운영 테스트는 개발채널 `체험마을AI사무장` `@chonmuseojang`에서 합니다.

등록 문장은 https://chonmuseojang.vercel.app/guide/register 에서 마을을 고른 뒤 복사합니다. 앞에 `등록`을 붙이지 않습니다.

등록 코드를 여는 비밀번호는 Vercel Production의 `GUIDE_PASSWORD`입니다. 값은 저장소와 이 문서에 적지 않습니다. 개발 초기화 화면의 `DEV_ADMIN_PASSWORD`와 다릅니다.

체험 이름 없는 첫 계정이 마을 운영자입니다. 체험 담당은 다른 카카오 계정으로, 문장 끝에 안내 페이지의 체험 이름을 붙여 그 다음에 등록합니다. 이미 다른 마을에 등록된 계정은 다시 등록되지 않습니다.

마을 운영자가 없으면 체험 담당 등록은 `먼저 마을 운영자를 등록해 주세요.`로 거절됩니다. 마을 운영자 자리가 있으면 `이 마을에는 이미 마을 운영자가 있습니다. 체험 이름을 붙여 주세요.`가 옵니다. 같은 체험을 다시 말하면 `이 체험에는 이미 담당자가 있습니다.`가 옵니다. 코드나 마을 이름이 다르면 `등록 코드가 마을과 맞지 않습니다.`가 옵니다.

등록이 끝나면 답장에 마을 ID와 역할이 나옵니다. 마을 운영자는 `마을ID 운영자로 등록되었습니다.`이고, 체험 담당은 `마을ID 체험 담당으로 등록되었습니다.`입니다.

## 홍보

마을 운영자만 그 마을 홍보를 담당합니다. 카카오의 홍보 사진은 해당 `village_id`의 소개글과 SNS 초안만 만들고 `is_public`은 꺼 둡니다. 관광객 화면은 웹에서 관광객에게 공개를 누른 뒤에 바뀝니다.

체험 담당은 `예약·홍보는 마을 운영자만 할 수 있습니다.`로 거절됩니다.

## 웹 로그인

카카오 등록은 `login_id`를 만들지 않습니다. 등록 답장의 마을 ID로 마을 운영자 행만 갱신합니다.

```sql
UPDATE operators
SET login_id = '원하는아이디'
WHERE village_id = '등록 답장에 나온 마을ID'
  AND role = 'village';
```

`login_id`는 전체에서 하나여야 합니다. 이 문장은 `kakao_user_id`를 바꾸지 않습니다. [supabase/seed.sql](../supabase/seed.sql)과 `scripts/load_demo_fixtures.py`는 V001 시연용이라 실제 마을에 실행하지 않습니다. 시드 SQL은 카카오 사용자 ID까지 덮습니다.

만든 아이디는 https://chonmuseojang.vercel.app/operator 의 로그인 칸에 넣습니다. 비밀번호는 없습니다. 이 화면에서 관광객에게 공개를 누르면 그 마을 홍보가 공개됩니다. 체험 담당 행에 아이디를 넣어도 홍보 화면은 열리지 않습니다.

## 다시 등록

잘못된 등록은 https://chonmuseojang.vercel.app/guide/dev 에서 그 마을의 운영자만 지운 뒤 같은 문장으로 다시 등록합니다. 마을과 등록 코드는 그대로입니다.
